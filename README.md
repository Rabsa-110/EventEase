# EventEase

EventEase is a web-based event management and ticketing platform
designed to make event discovery, registration, ticket management,
and attendee check-in easier for both attendees and organizers.

## Features

- User registration and login
- Event discovery and search
- Event creation and management
- Ticket registration
- Digital tickets with QR codes
- QR-based event check-in
- Organizer dashboard
- Admin dashboard
- Event analytics
